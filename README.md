 📌 Objective

The goal of this project is to analyze customer purchasing behavior to identify high-value customers, understand buying patterns, and provide actionable business insights.

 📂 Dataset

* Superstore Dataset (Kaggle)
* Contains order-level data including sales, customers, and regions

 🛠️ Tools & Technologies

* SQL (MySQL) – Data analysis
* Power BI – Data visualization & dashboard
* Excel – Data cleaning

🔄 Project Workflow

1. Data Cleaning & Preparation
2. SQL Analysis (Customer-level metrics)
3. Customer Segmentation (High / Medium / Low)
4. Dashboard Creation in Power BI
5. Insights & Business Recommendations

 📈 Key Insights

* Top 20% of customers contribute the majority of total revenue
* A large portion of customers are low-frequency buyers
* High-value customers have significantly higher average order value
* Revenue is highly concentrated among a small group of customers

💡 Business Recommendations

* Focus marketing efforts on high-value customers
* Introduce loyalty and reward programs for repeat buyers
* Target low-value customers with promotional campaigns
* Encourage repeat purchases through personalized offers

 🧠 Customer Segmentation Logic

Customers are segmented based on total sales:

* 🟢 High Value → Sales > 5000
* 🟡 Medium Value → Sales between 2000–5000
* 🔴 Low Value → Sales < 2000


 📌 SQL Analysis Performed

* Top customers by revenue
* Customer order frequency
* Average order value
* Combined customer metrics query
* Customer segmentation using CASE statement

 📊 Dashboard Features

* KPI Cards (Total Sales, Total Customers, Avg Order Value)
* Top 10 Customers by Sales
* Customer Segmentation (Donut Chart)
* Interactive filters (Customer Segment, Region)

 🧾 Conclusion

This project demonstrates how customer data can be transformed into meaningful insights using SQL and Power BI. By identifying high-value customers and analyzing purchasing behavior, businesses can make data-driven decisions to improve customer retention, optimize marketing strategies, and increase overall revenue.
